# Contributing to Puzzary Official Plugins

Open or choose an issue before substantial work. Keep each puzzle module
independent, preserve its stable slug and saved-payload contract, and update its
focused verification coverage. Run `python scripts/build.py` before submitting
a pull request; it validates every manifest and produces deterministic release
archives with licensing and SHA-256 checksums.

Contributions are submitted under Apache-2.0 as described by section 5 of the
license unless explicitly stated otherwise. Identify copied or adapted
third-party material and retain its license and attribution.

AI tools may assist development, but the human submitter remains responsible
for understanding, testing and licensing the contribution and for checking that
generated material does not reproduce incompatible third-party code. Disclose
substantial AI assistance in the pull request when it materially shaped the
implementation.

Report vulnerabilities privately using GitHub's security advisory form rather
than a public issue. See [SECURITY.md](SECURITY.md).
