# Security policy

Security fixes are provided for the latest official-plugin release compatible
with the latest supported Puzzary beta. Older module releases are unsupported.

Report vulnerabilities privately at:

https://github.com/barrelcollector/puzzary-official-plugins/security/advisories/new

Include the affected module/version, reproduction steps and impact. Do not open
a public issue for an unpatched vulnerability or include real credentials and
production data.
